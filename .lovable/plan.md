Conectar o projeto atual à conta do GitHub do usuário e criar um repositório sincronizado para o código do site.

## Passos
1. Abrir o menu Plus (+) no canto inferior esquerdo do chat, ir em GitHub → Connect project.
2. Autorizar o aplicativo Lovable no GitHub.
3. Selecionar a conta/organização e o nome do repositório.
4. Criar o repositório no GitHub com o código atual.
5. Verificar a sincronização ativa e informar o link do repositório.

## Resultado esperado
Repositório criado no GitHub com o código atual do site, sincronizando automaticamente com o Lovable.
